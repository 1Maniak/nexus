# Changelog — Nexus

Все заметные изменения в проекте «Nexus» документируются здесь.

Формат основан на Keep a Changelog, проект придерживается Semantic Versioning.

---

## [v1.4.1] — 2026-11-08

### Изменено

- Изменено управление файловой системой.
- Изменен системный промпт.
- Удалены некоторые команды для управления файловой системой.
- Временно удален агентный цикл.

### Исправлено

- Повторы и смешение языков (китайский в ответах): снижена temperature, усилен repeat_penalty, добавлен max_tokens.
- Идентичность Nexus: быстрые ответы на «привет», «кто я», «кто ты» без вызова LLM.
- Контекст: RAG больше не копится в истории, история обрезается до 12 сообщений.
- Единое имя модели во всех запросах (qwen2.5-3b-instruct-q4_k_m.gguf).

### Оптимизировано

- Снижена вероятность повреждения базы данных (удалена сложная логика инкрементального обновления).
- Весь код прошел рефакторинг.

## [v1.4.0] — 2026-08-08

### Добавлено

- Переход на модель Qwen2.5-3B (улучшение качества и скорости ответов).
- GPU-ускорение через Vulkan (работает на видеокартах с поддержкой Vulkan).
- Полноценная работа с файлами: чтение (прочитай), перезапись (запиши), добавление в конец (добавь), открытие файлов и папок (открой).
- Команда !последний для открытия последнего использованного файла или папки.
- Улучшенная обработка путей с пробелами.
- ROADMAP.md — план развития проекта.

### Изменено

- Временный отказ от агентного цикла (обработка ключевых слов) для повышения стабильности.
- Системный промпт адаптирован под текущий режим работы.
- Код очищен от экспериментальных функций (list_memory, сжатие истории).

### Исправлено

- Нексус стабильно отвечает на простые вопросы без зависаний.
- Исправлена ошибка открытия папок через start (теперь используется explorer).

### Оптимизировано

- Загрузка базы знаний ускорена за счёт параллельных запросов к эмбеддеру.
- Кэширование эмбеддингов в knowledge_state.json для повторных запусков.

## [v1.1.0] — 2026-08-05

### Добавлено

- Переход с JSON на SQLite для хранения памяти (nexus_memory.db).
- Полнотекстовый поиск FTS5 для быстрого поиска по диалогам и знаниям.
- Интернет-поиск через DuckDuckGo (функция webSearch).
- Автоматическое определение поисковых запросов по ключевым словам: погода, курс, доллар, новости и другие.
- Команда !поиск для явного запроса поиска в интернете.
- Извлечение чисел из результатов поиска для курсов валют и цен.
- Логи поиска сведены к минимуму (только количество результатов).
- Скрипт start.bat для автоматического запуска llama-server и клиента в Windows Terminal (две вкладки).
- Системный промпт обновлён: Нексус знает о своих возможностях (поиск, память).

### Изменено

- Память полностью перенесена в SQLite (вместо memory.json).
- Векторные эмбеддинги хранятся в BLOB-полях SQLite.
- Функция поиска переписана на полнотекстовый поиск FTS5.
- Код main.go и storage.go объединены в один файл для упрощения сборки.
- Параметры запуска llama-server оптимизированы для CPU (Xeon).

### Удалено

- Зависимость от memory.json (больше не используется).
- Отдельный файл storage.go (объединён с main.go).
- Избыточные логи поиска (вывод первых результатов, сообщения о добавлении в контекст).

### Исправлено

- Ошибка чтения PDF (замена pdf.Open на корректный парсинг).
- Ошибка поиска в интернете (добавлены заголовки User-Agent).
- Обработка статуса 202 от DuckDuckGo (повтор запроса через 1 секунду).

### Оптимизировано

- Загрузка базы знаний: параллельное получение эмбеддингов (5 горутин).
- Кэширование эмбеддингов в knowledge_state.json.
- Уменьшен размер шрифта логов (системные сообщения серым цветом).

## [v1.0.0] — 2026-07-11

### Добавлено

- Первая рабочая версия «Nexus» — локальный ИИ-помощник с долговременной памятью.
- Клиент на Go (500+ строк кода):
  - Потоковый вывод ответов.
  - Цветовая маркировка (системные сообщения, ошибки).
  - Интерактивный диалог с командой exit для выхода.
- Модель: Qwen2.5-Coder-7B-Instruct (Q5_K_M). Запускается через llama-server (движок llama.cpp).
- Память (RAG):
  - Векторная память через эмбеддинги (Ollama + nomic-embed-text).
  - Поиск по косинусному расстоянию с приоритетом знаний.
  - Сохранение диалогов и знаний в memory.json.
- База знаний:
  - Автоматическая загрузка файлов из папки base.
  - Поддерживаемые форматы: .txt, .md, .go, .json, .pdf, .docx, .csv, .html.
  - Разбивка на чанки и добавление в память.
- Инкрементальное обновление базы знаний:
  - Отслеживание изменений файлов через хеши.
  - Добавление только новых или изменённых файлов.
  - Автоматическое удаление фрагментов удалённых файлов.
  - Состояние хранится в knowledge_state.json.
- Системный промпт:
  - Роль Нексуса: помощник Максима.
  - Примеры диалогов (few-shot).
  - Обязательный русский язык и уважительный стиль.

### Исправлено

- Исправлены ошибки работы с PDF (замена pdf.Open на корректный парсинг).
- Улучшена функция чтения CSV (оптимизирована конкатенация строк).
- Устранены конфликты с Vulkan (возврат к стабильной CPU-версии).

### Оптимизировано

- Параметры запуска llama-server:
  - Контекстное окно: -c 4096 (временно, до апгрейда ПК).
  - Количество потоков: -t 8 для полной загрузки CPU.
  - Отключены --no-mmap и --mlock для стабильности.
