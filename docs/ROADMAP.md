## Отдельный трек: NetScope

**Что это:** Утилита для обычных людей, которая объясняет, почему плохо работает интернет.

**Этапы:**
- **MVP (CLI, Go, ПК):** Сбор метрик (ping, packet loss, скорость, Wi-Fi), история в SQLite.
- **v1.0 (GUI, ПК):** Объяснения простым языком, рекомендации, интеграция с Nexus.
- **Mobile (Flutter):** Упрощённая версия для Android/iOS.

**Статус:** Идея зафиксирована. Реализация ещё не начата.
