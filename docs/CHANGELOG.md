## [v1.7.0] - 2026-11-08

### Добавлено
- **Стриминг ответов (SSE)**: текст появляется по мере генерации, как в ChatGPT.
- **Drag & Drop**: поддержка перетаскивания файлов в окно чата для добавления в базу знаний.
- **Выдвижная панель управления**: отображает статус сервера, токены, записи в БД и файлы (скрыта по умолчанию за кнопкой-шестеренкой).
- **API**: эндпоинты `/api/status` и `/api/upload` для интеграции с интерфейсом.
- **Автовыключение**: сервер корректно завершает процессы при закрытии вкладки браузера (через `sendBeacon`).

### Изменено
- **UI/UX**: переработан дизайн (светлая/темная тема, градиенты сообщений, новые иконки).
- **Запуск**: браузер открывается моментально, а загрузка тяжелой модели (llama-server) и БД уходит в фон.
- **Поле ввода**: адаптивная высота с ограничением (до 200px) и корректное сжатие при удалении текста.
- **Кнопка отправки**: фиксированный размер для идеального выравнивания с полем ввода.

### Исправлено
- **Ошибка `nil pointer dereference`**: падение сервера при запросе статуса до инициализации БД.
- **Мигание окон консоли**: процессы `taskkill` теперь завершаются скрыто (флаг `HideWindow`).
- **Кнопка «Копировать»**: исправлено позиционирование внутри блока кода.

## [v1.6.0] - 2026-11-07

Мажорное обновление веб-интерфейса и оптимизация работы на слабом железе.

### Добавлено

- **Веб-интерфейс (`web/`)**: локальный чат в браузере с темной темой. Добавлена анимация загрузки (три прыгающие точки) во время генерации ответа.
- **Веб-сервер (`web.go`)**: обработка POST-запросов от браузера с интеграцией RAG-поиска.
- **Кнопка «Выключить Nexus»**: в веб-интерфейсе появилась кнопка, которая корректно завершает работу всех фоновых процессов.
- **Файл конфигурации (`config.json`)**: пути к llama-server и модели вынесены из кода.
- **Автозапуск браузера (`browser.go`)**: при старте Nexus автоматически открывает страницу `http://localhost:8081`.
- **Очистка процессов (`cleanup.go`)**: при закрытии программы автоматически убивается процесс `llama-server.exe`.

### Изменено

- **Разделение на Dev и Prod версии**: 
  - `nexus-dev.exe` запускается с консолью, открывает вкладки с логами сервисов и браузер.
  - `nexus.exe` собирается с флагом `-H windowsgui`, работает скрыто в фоне и открывает только браузер.
- **Пути к файлам**: база данных, папка `base`, конфиг и веб-интерфейс теперь ищутся относительно расположения самого `.exe` файла.
- **Оптимизация скорости**: сокращен системный промпт, `maxHistoryMessages` уменьшено до 6, `maxRAGResults` до 2. Время ожидания первого токена сократилось с 30 до 5-8 секунд.
- **`launcher.go`**: для запуска сервера теперь генерируется временный `.bat` файл.

### Исправлено

- Ошибка `unable to open database file`.
- Ошибка `404` при запросе эмбеддингов.
- Конфликт портов (`bind: Only one usage of each socket address`).

## [v1.5.0] - 2026-08-12

### Добавлено

- Реализован векторный семантический поиск (RAG) на основе косинусного сходства вместо полнотекстового FTS.
- Расширен список ключевых слов для автоматического интернет-поиска.
- Добавлена функция `searchByVector`.
- Увеличен `maxHistoryMessages` до 20.
- Увеличен `maxGeneratedTokens` до 2048.

### Изменено

- Поиск по памяти теперь по умолчанию использует векторный поиск.
- Обновлён системный промпт.

## [v1.0.0] - 2026-07-11

### Добавлено

- Первая рабочая версия «Nexus» - локальный ИИ-помощник с долговременной памятью.
