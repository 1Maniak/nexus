## [v1.0.0] — 2026-08-08

### Добавлено

**Базовые команды:**

- **`git status`** — проверка состояния репозитория  
- **`git add .`** — добавление всех изменений в коммит  
- **`git add <файл>`** — добавление конкретного файла  
- **`git commit -m "сообщение"`** — создание коммита  
- **`git push`** — отправка изменений на GitHub  
- **`git push -u origin main`** — первый пуш в новом репозитории

**Работа с тегами (версиями):**

- **`git tag -a vX.Y.Z -m "описание"`** — создание нового тега  
- **`git tag`** — просмотр всех тегов  
- **`git push --tags`** — отправка тегов на GitHub  
- **`git tag -d vX.Y.Z`** — удаление тега локально  
- **`git push --delete origin vX.Y.Z`** — удаление тега на GitHub

**Работа с ветками:**

- **`git checkout -b <ветка>`** — создание и переход в новую ветку  
- **`git checkout main`** — переключение на основную ветку  
- **`git branch`** — просмотр всех веток  
- **`git merge <ветка>`** — слияние ветки с текущей  
- **`git branch -d <ветка>`** — удаление ветки

**Откаты и восстановление:**

- **`git checkout -- <файл>`** — отмена изменений в файле до последнего коммита  
- **`git reset --soft HEAD~1`** — отмена последнего коммита (сохраняет изменения)  
- **`git reset --hard HEAD~1`** — отмена последнего коммита (удаляет изменения)  
- **`git checkout <хеш-коммита>`** — переход к конкретному коммиту

**Просмотр и диагностика:**

- **`git log --oneline`** — краткая история коммитов  
- **`git log -p`** — история с изменениями  
- **`git diff <файл>`** — что изменилось в файле  
- **`git remote -v`** — просмотр удалённого репозитория

**Связь с GitHub Issues:**

- **`git commit -m "описание, closes #<номер>"`** — закрытие Issue при пуше  
- **`git commit -m "описание, refs #<номер>"`** — упоминание Issue без закрытия
