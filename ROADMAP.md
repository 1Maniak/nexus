# Roadmap — Nexus

## Цели на будущее

### Инструменты и действия

- Генерация файлов — Nexus должен уметь создавать файлы по запросу (.txt, .md, .go, .json, .html и др.).
- Управление Git — Nexus должен выполнять команды Git: коммиты, создание тегов (SemVer), пуш, работа с ветками.
- Автоматическое обновление CHANGELOG — при создании нового тега Nexus должен предлагать или автоматически обновлять CHANGELOG.md.
- **Сетевая диагностика (NetScope)** — отдельная утилита для ПК и телефона, которая собирает данные о сети, находит паттерны и объясняет причины проблем с интернетом простым языком. Nexus сможет управлять ею как модулем.

### Ум и агентность

- Агентный цикл (tool calling) — Nexus сам решает, когда вызывать инструменты.
- Управление ПК — открытие приложений, клики, работа с файлами.
- Самообучение — улучшение через RAG и дообучение.

### Голос и зрение

- STT + TTS — голосовое общение.
- Анализ скриншотов — Нексус видит твой экран.

### Платформы

- Портирование на телефон (Android/iOS).
- Упаковка в один исполняемый файл (для лёгкого распространения).

---

## Как это будет реализовано

1. Генерация файлов -> добавить функцию write_file(path, content) и связать с промптом.
2. Управление Git -> добавить функции git_commit, git_tag, git_push с безопасным исполнением.
3. SemVer -> автоматическое создание тегов через анализ изменений.
4. **Сетевая диагностика (NetScope)** -> отдельный проект на Go (CLI для ПК, потом Flutter для телефона). Собирает метрики: ping, packet loss, jitter, скорость, уровень Wi-Fi сигнала, загруженность каналов, DNS-задержки. Хранит историю в SQLite, ищет паттерны, коррелирует с погодой (OpenWeatherMap) и статусом провайдера (Downdetector). Интеграция с Nexus через модуль-обёртку: Nexus вызывает `netscope diagnose` и получает JSON-отчёт.

## Отдельный трек: NetScope

### Что это

Утилита для обычных людей, которая объясняет, почему плохо работает интернет. Не для айтишников — для всех.

### Этапы

**MVP (CLI, Go, ПК):**
- Сбор метрик: ping до шлюза, DNS, внешних серверов.
- Потери пакетов, джиттер.
- Скорость загрузки/отдачи (speedtest).
- Уровень Wi-Fi сигнала, канал, загруженность соседями.
- История в SQLite.

**v1.0 (GUI, ПК):**
- Простой интерфейс (Wails/Fyne).
- Объяснения простым языком («канал Wi-Fi перегружен», «провайдер тормозит», «возможны помехи из-за грозы»).
- Рекомендации.
- Корреляция с погодой (OpenWeatherMap) и статусом провайдера.
- Интеграция с Nexus как модуль.

**Mobile (Flutter):**
- Android/iOS.
- Упрощённая версия: базовые метрики + объяснения.

### Монетизация (опционально)

- Freemium: базовая диагностика бесплатно, детальный анализ + история + рекомендации по подписке.
- B2B: лицензия для провайдеров и техподдержки.
